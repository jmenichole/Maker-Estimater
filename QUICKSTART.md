# Quick Start Guide

Get your AI-powered Maker Estimater running in 5 minutes!

## 🚀 Fastest Path to Deployment

### Step 1: Get an OpenAI API Key (2 minutes)

1. Visit [platform.openai.com/api-keys](https://platform.openai.com/api-keys)
2. Sign up or log in
3. Click "Create new secret key"
4. Copy the key (starts with `sk-proj-...`)

💡 **Tip**: New accounts get $5 in free credits!

### Step 2: Deploy to Vercel (2 minutes)

1. Visit [vercel.com](https://vercel.com)
2. Sign in with GitHub
3. Click "Add New Project"
4. Import this repository: `jmenichole/Maker-Estimater`
5. Add environment variable:
   - Name: `OPENAI_API_KEY`
   - Value: Your API key from Step 1
   - Environments: Check all boxes
6. Click "Deploy"

### Step 3: Use Your Calculator (1 minute)

1. Wait for deployment to complete (~30 seconds)
2. Click the preview URL (e.g., `your-project.vercel.app`)
3. See the green "AI-Powered Pricing Active" banner? ✅ You're ready!
4. Enter project details and click "Calculate Quote"

## 🆘 Troubleshooting

### "AI service unavailable" message?

- ✅ Check OpenAI API key is set in Vercel
- ✅ Verify you have OpenAI credits
- ✅ Redeploy the project

### Green banner not showing?

- ✅ Make sure you deployed to Vercel (not GitHub Pages)
- ✅ Check environment variables are set
- ✅ Try hard refresh (Ctrl+Shift+R)

### Still having issues?

Open an issue on [GitHub](https://github.com/jmenichole/Maker-Estimater/issues)
